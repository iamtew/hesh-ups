# Overview

hesh-ups is a named, laid-out overlay for OBS. One operator, one Windows box, localhost.

Lay out named boxes on the composer plot. Each slot is media and/or a text template. Hit a URL (Streamer.bot, Stream Deck, a browser) and that slot appears on stream. Composer outlines are not the stream picture. Streamer.bot stays the brain. This app does not parse Twitch, do TTS, or run goals.
